# 工作流编辑与运行一体化计划

## 目标与已确认边界

- 分离页只保留单模型和快捷 Ensemble；工作流推理迁到工作流模块。
- 工作流管理页统一使用“打开工作流”，以独立系统弹窗打开对应的简易或高级编辑器。
- 输入节点选择文件、文件夹；输出节点选择本次目录或全局默认目录。
- 输入文件和绝对输出目录属于运行会话，不写入工作流定义或导出文件。
- 工作流保存节点、连线、模型、处理参数、格式、命名及画布布局。
- 运行期间允许编辑；已提交任务使用不可变快照，编辑用于下一次运行。
- 同一编辑器区分当前流程和本次执行；执行画布只读，可缩放、平移和查看节点。
- 复用任务队列、并发限制、批处理、取消、历史与结果；本分支不合并或推送主分支。

## 输入与输出

- 文件夹由 Studio 扫描为文件列表，提交时冻结，每个文件完整执行一次流程。
- 简易编辑器保留固定输入和汇总输出节点；高级编辑器支持现有多个加载和保存节点。
- 多输入流程明确指定主输入；一个多文件输入驱动批次，其他输入绑定单文件。多个多文件输入在没有明确配对规则时拒绝运行。
- 默认输出目录在提交时解析并冻结；每个输出绑定可选择本次目录。
- SDK 输出目录字段仅为相对目录，不能直接塞入绝对目录。任务在私有临时目录写出，按保存节点身份发布到最终目录，保留原子重名保护。
- 本次路径与执行状态独立于 definition、撤销历史和 dirty 状态；导入固定路径保持兼容，不自动改写原始定义。

## 执行与状态

- 保存校验结构及元数据；运行另外校验输入、目录、参数、连线和有效输出。
- 有修改时先保存捕获的流程版本再提交；版本冲突不启动任务。
- 任务记录完整运行快照：来源工作流 ID/版本、原始定义、有效执行定义、输入绑定、输出绑定、主输入及节点映射。
- 重试使用原快照，不重新套用当前草稿或全局设置。
- 透传 pymss 的 node_id、node_type、node_fraction、overall_fraction、音频序号和计数单位。
- 简易内部合并/保存节点映射到可见节点或输出行；无可靠节点上下文的错误显示为运行级错误。
- 主窗口负责调度与历史写入；切换页面不会取消任务。迟到进度不能恢复终态任务。

## 实施步骤

1. 建立运行绑定、快照、校验与节点映射契约；扩展 task store 与 Worker，保持旧入口兼容。
2. 为两个编辑器添加输入/输出节点控件、保存与运行动作、本次执行画布及日志/结果面板。
3. 工作流管理页统一打开入口；调整主窗口导航与编辑器生命周期；移除分离页工作流选择入口。
4. 聚焦测试、完整前端/Python回归、类型检查与构建；浏览器实际检查简易/高级配置与运行状态。
5. 汇总效果截图、验证结果和剩余限制，交由用户决定后续修改、撤销或合并。

## 验收

- 分离页与工作流输入互不影响；单模型及快捷 Ensemble 可继续运行。
- 两种工作流均可在对应编辑器内选择输入输出、保存、提交、取消、查看日志和结果。
- 单文件、目录批次、多槽异文件绑定正确；目录扫描不会被误当成原生整批音频加载。
- 默认/指定目录、多输出、并发同名输出、重试目标正确。
- 修改或删除节点不改变已排队/执行快照；执行视图和原草稿状态分离。
- 页面切换、重新打开编辑器、旧链接及旧 YAML/Comfy 导入可恢复或兼容。
- Python/前端回归测试与 pnpm build 通过；真实 Worker 的音频运算与输出发布得到验证。

### 已实现

- 分离页移除工作流选择，单模型及快捷 Ensemble 保留；旧工作流链接转到工作流模块。
- 工作流列表统一打开独立窗口编辑器；两种编辑器都有保存、运行、取消及批次选择。

- 回收工作流结果只处理明确的输出文件，不自动删除用户选择的输出目录。

### 第一版边界

- 简易继续保留一个输入节点和汇总输出节点；高级支持现有多个输入/输出节点。
- 多输入仅支持一个批次输入配合其他单文件输入；多个文件列表不进行自动配对。
- 文件夹扫描沿用既有媒体扫描器，暂未新增独立递归选项。
- 运行绑定只保留在当前应用会话，重启后需重新选择；已提交任务的快照和路径保存在任务历史。
- 浏览器预览用于查看界面；实际文件选择、拖放及桌面 IPC 应在 `pnpm tauri dev` 中验收。此次未替用户切换已安装版本或合并到主分支。

## 容器形式修正

用户最终明确要求沿用原先的独立系统弹窗，不使用主窗口内的编辑页面。工作流管理页保持在主窗口，简易和高级工作流均调用现有窗口命令打开或聚焦对应弹窗；运行后弹窗保持打开。主窗口唯一负责队列与历史，弹窗通过请求回执和只读任务镜像查看节点进度、日志及结果。关闭弹窗不取消任务，重新打开可恢复本次输入输出绑定和执行状态。窗口创建失败时显示错误，不自动转成主窗口内页面。
